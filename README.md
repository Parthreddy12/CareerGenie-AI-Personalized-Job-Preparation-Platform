# CareerGenie-AI-Personalized-Job-Preparation-Platform.
CareerGenie AI is an AI-powered job preparation platform that helps students become placement-ready. It analyzes resumes, identifies skill gaps, recommends suitable jobs, and provides personalized preparation through aptitude tests, coding challenges, interviews, and an AI-powered mock interview agent.
