# 🤖 CareerGenie AI

### Personalized Job Preparation Platform

> **Prepare Smarter. Practice Better. Get Career Ready.**

CareerGenie AI is an AI-powered job preparation platform designed to help students and job seekers prepare for placements through personalized resume analysis, job recommendations, aptitude practice, coding challenges, interview preparation, and AI-powered mock interviews.

---

## 📌 About The Project

Preparing for a job or campus placement often requires using multiple platforms for resume improvement, aptitude tests, coding practice, and interview preparation.

**CareerGenie AI** brings these activities together into one platform and uses Artificial Intelligence to provide a personalized job preparation experience.

The system analyzes the candidate's resume and helps guide them through different stages of job preparation.

---

## ✨ Features

### 📄 Resume Analysis
- Upload and analyze your resume
- Evaluate resume quality
- Identify skills and important information
- Detect missing or improvable sections
- Get AI-based suggestions

### 💼 Job Recommendation
- Recommend suitable job roles
- Match candidate skills with job requirements
- Identify skill gaps

### 🧠 Aptitude Test
- Quantitative aptitude
- Logical reasoning

- Practice and assessment

### 💻 Coding Practice

- Programming problem solving
- Coding round preparation
- Multiple programming languages

### 🎤 Interview Preparation
- HR interview preparation
- Technical interview preparation
- Common interview questions
- Practice-based preparation

### 🤖 AI Agent Interview
- AI-powered mock interview
- AI acts as an interviewer
- Dynamic interview questions
- Candidate response evaluation
- Personalized feedback
- Interview performance analysis

⚙️ Installation
1. Clone the repository
git clone YOUR_REPOSITORY_URL
2. Navigate to the project
cd CareerGenie-AI
3. Install Python dependencies
pip install -r requirements.txt
4. Configure environment variables

Create a .env file:

API_KEY=your_api_key
DATABASE_URL=your_database_url

⚠️ Never upload API keys, passwords, or other sensitive information to GitHub.

5. Run the project

Start the required frontend, backend, and AI services according to your project configuration.
